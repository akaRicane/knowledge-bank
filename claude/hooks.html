Hooks

Shell scripts or Python scripts that Claude Code executes automatically in response to tool use events. Used for security reminders, linting, and custom enforcement.

hooks claude-code Last updated: 2026-05-14

How hooks work

Hooks are scripts registered in .claude/settings.json under a "hooks" key. Claude Code runs them automatically when matching tool events occur. The script's exit code controls whether the tool use proceeds:

Exit codeEffect
0Allow — tool use proceeds normally
2Block — tool use is cancelled; stdout is shown to the user
any otherWarning — tool use proceeds but stdout is shown as a warning

Hooks receive context about the tool call (file path, content being written, tool name) via environment variables or stdin, depending on the hook type.

Hook types

Hook typeWhen it runs
PreToolUseBefore a tool call executes — can block it
PostToolUseAfter a tool call completes
NotificationWhen Claude Code sends a notification to the user
StopWhen Claude Code finishes its turn

Each hook type can have a matcher to filter which tool names trigger it (e.g. "Edit|Write|MultiEdit").

security_reminder_hook

A PreToolUse hook that runs before every Edit, Write, or MultiEdit tool call. It scans the file path and content being written for known security anti-patterns and warns (or blocks) when one is found.

File: .claude/hooks/security_reminder_hook.py

Session deduplication

Each warning is shown at most once per session. The hook writes a session state file to a temp directory. If a pattern has already been warned about in the current session, the hook exits 0 (allow) silently instead of warning again. State files older than 30 days are cleaned up automatically.

Disable with: ENABLE_SECURITY_REMINDER=0 environment variable.

Adding custom patterns

Patterns are defined as a list of tuples in the hook script:

SECURITY_PATTERNS = [
    # (regex_pattern, warning_key, warning_message)
    (
        r'child_process\.exec\(',
        'child_process_exec',
        "⚠ child_process.exec() detected — vulnerable to command injection.\n"
        "Use execFile() or a safe wrapper that avoids shell interpretation.",
    ),
    # Add your own patterns here:
    (
        r'my_dangerous_function\(',
        'my_dangerous_function',
        "⚠ my_dangerous_function() detected — explain the risk here.",
    ),
]

Full hook structure

#!/usr/bin/env python3
"""Pre-tool-use security reminder hook for Claude Code."""

import json, os, sys, re, hashlib, time
from pathlib import Path

ENABLE = os.environ.get('ENABLE_SECURITY_REMINDER', '1') != '0'
SESSION_ID = os.environ.get('CLAUDE_SESSION_ID', 'default')

SECURITY_PATTERNS = [
    # (regex, key, message)
    (r'eval\(', 'eval', "⚠ eval() detected — arbitrary code execution risk."),
    # ... more patterns ...
]

def get_state_file() -> Path:
    state_dir = Path('/tmp/claude_security_hook')
    state_dir.mkdir(exist_ok=True)
    session_hash = hashlib.md5(SESSION_ID.encode()).hexdigest()[:8]
    return state_dir / f'session_{session_hash}.json'

def load_state() -> set:
    f = get_state_file()
    if f.exists():
        try:
            return set(json.loads(f.read_text()).get('shown', []))
        except Exception:
            return set()
    return set()

def save_state(shown: set):
    get_state_file().write_text(json.dumps({'shown': list(shown), 'ts': time.time()}))

def main():
    if not ENABLE:
        sys.exit(0)

    try:
        tool_input = json.loads(sys.stdin.read())
    except Exception:
        sys.exit(0)

    content = tool_input.get('content', '') + tool_input.get('file_path', '')
    shown = load_state()
    warnings = []

    for pattern, key, message in SECURITY_PATTERNS:
        if key not in shown and re.search(pattern, content):
            warnings.append((key, message))

    if warnings:
        for key, message in warnings:
            shown.add(key)
            print(message)
        save_state(shown)
        sys.exit(2)  # block tool use

    sys.exit(0)

if __name__ == '__main__':
    main()

Registering in settings.json

{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "Edit|Write|MultiEdit",
        "hooks": [
          {
            "type": "command",
            "command": "python3 .claude/hooks/security_reminder_hook.py"
          }
        ]
      }
    ],
    "Stop": [
      {
        "hooks": [
          {
            "type": "command",
            "command": "echo 'Claude finished.' | terminal-notifier -title 'Claude Code'"
          }
        ]
      }
    ]
  }
}
ℹ
Use relative paths (.claude/hooks/...) so the hook works from any machine that checks out the repo. Absolute paths break on other machines.

Writing custom hooks

  • Hooks can be Python, shell, or any executable script.
  • Read tool context from stdin as JSON — the shape depends on the tool.
  • Print messages to stdout — they are shown to the user.
  • Exit 0 to allow, 2 to block.
  • Keep hooks fast — they run on every matching tool call.
  • Use session-state files in /tmp/ to avoid repeated warnings.

Minimal hook example

#!/usr/bin/env python3
"""Block writes to files matching a pattern."""
import json, sys

tool_input = json.loads(sys.stdin.read())
file_path = tool_input.get('file_path', '')

if '.env.production' in file_path:
    print("⚠ Blocked: do not overwrite .env.production directly.")
    sys.exit(2)

sys.exit(0)
