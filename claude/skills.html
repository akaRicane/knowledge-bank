Skills

Skills are invocable specializations registered in .claude/skills/. Each skill gives Claude Code a focused domain perspective for a specific task type.

How skills work

Skills live in .claude/skills/skill-name/SKILL.md. The user invokes them with /skill-name in the Claude Code chat. Unlike agents (which run as subprocesses), skills inject a specialized system prompt directly into the current conversation.

frontend-design

Creates distinctive, production-grade frontend interfaces with high design quality. Use when building web components, pages, or applications where visual design matters.

Core philosophy: Avoids generic "AI slop" aesthetics. Generates creative, polished code that is context-specific and memorable. Every interface has a reason to look the way it does.

Design thinking process

Before writing any code, answer four questions:

  1. Purpose — What problem does this interface solve? Who uses it?
  2. Tone — Pick an extreme aesthetic and commit to it: brutally minimal, maximalist, retro-futuristic, organic, luxury, playful, editorial, brutalist, art deco, soft/pastel, industrial, etc.
  3. Constraints — What are the technical requirements?
  4. Differentiation — What makes this interface unforgettable?

5 aesthetic dimensions

1. Typography

  • Choose distinctive fonts — not generic ones (no Arial, Inter, system-ui).
  • Pair a distinctive display font with a refined body font.
  • Avoid overused choices (Space Grotesk, etc.).

2. Color & theme

  • Commit to a cohesive aesthetic — use CSS custom properties.
  • Dominant colors with sharp accents beat timid, evenly-distributed palettes.
  • Avoid clichéd color schemes (purple gradients on white, etc.).

3. Motion

  • Animations for effects and micro-interactions.
  • CSS-only for HTML; Motion library for React.
  • Focus on high-impact moments: page load staggered reveals, hover surprises.
  • Scroll-triggering where appropriate.

4. Spatial composition

  • Unexpected layouts — asymmetry, overlap, diagonal flow.
  • Grid-breaking elements.
  • Generous negative space OR controlled density — pick one and commit.

5. Backgrounds & visual details

  • Atmosphere and depth, not flat solid colors.
  • Contextual effects: gradient meshes, noise, patterns, layered transparencies.
  • Dramatic shadows, decorative borders, grain overlays.

Anti-patterns to never use

  • Overused font families: Inter, Roboto, Arial, system fonts.
  • Clichéd color schemes: purple gradient on white, hero with a blue button.
  • Predictable layouts: hero → features → CTA → footer.
  • Cookie-cutter components with no context-specific character.
✦
Match implementation complexity to vision. Maximalist designs need elaborate code. Minimalist/refined designs need restraint and precision — not less effort, different effort.

Skill file template

Place in .claude/skills/my-skill/SKILL.md:

---
name: my-skill
description: One-line description of what this skill does and when to use it.
---

# My Skill

## When to invoke
Describe the trigger conditions: what kind of task the user is doing
that makes this skill relevant.

## Process
Describe how Claude Code should approach the task differently with this skill active.
What questions to ask first, what principles to apply, what to avoid.

## Output
Describe what the skill should produce — code, analysis, questions, etc.
