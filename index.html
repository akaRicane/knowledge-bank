Usage as a submodule

git submodule add <remote-url> knowledge_bank

# Update after upstream changes
git submodule update --remote knowledge_bank

To navigate all knowledge, start from this index.html and follow theme links. Each theme index lists its documents with short descriptions. Claude agents should read index.html first, then follow links to the relevant theme.

Authoring conventions

  • One HTML file per concern — never cram unrelated topics together.
  • Common patterns go in common/; version-locked content in v6/, v7/, etc.
  • Every <section> must have an id for deep-linking.
  • CSS path is always relative: count directory depth and adjust the href to _shared/styles.css.
  • No external CDN links — the repo must work offline.
  • Update the version-badge date when significantly editing a file.
  • Add new themes to this index.html card grid immediately.
