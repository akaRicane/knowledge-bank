This theme is project-specific. Design direction, color palettes, typography choices, and component patterns belong to the project that uses this knowledge bank. Add your project's design documentation here rather than sharing it across projects.

What to document here

  • Artistic direction — concept, tone, mood, visual references.
  • Color system — palette tokens, semantic aliases, dark/light mode.
  • Typography — font families, type scale tokens, usage rules per font role.
  • Spacing — grid system, spacing token scale.
  • Motion — transition tokens, animation conventions.
  • Component patterns — layout patterns, entity viewer pages, card grids.
  • Do-not rules — anti-patterns specific to this project's visual language.

Token source convention

Authoritative token values always live in CSS source files, not in this documentation. Document token names and intent here. When in doubt, read the source CSS.
