Infrastructure

Project-specific environment configuration, deployment notes, and service wiring.

ℹ
This theme is project-specific. Environment variables, connection strings, hostnames, and deployment targets belong to the project that uses this knowledge bank. Add your project's infrastructure documentation here.

What to document here

  • Environment variables — full table of vars, types, example values, and which are required vs optional.
  • Database — connection name, host, port, migration strategy.
  • CORS — allowed origins, credentials policy.
  • Security — CSRF config, HSTS, content security policy.
  • External services — SMTP provider, CDN, object storage, third-party APIs.
  • Deployment — how to build, deploy, and roll back.

Framework-level config

Generic framework configuration patterns (AdonisJS config/ files, Vite setup, etc.) are documented in the relevant framework theme (e.g. AdonisJS v6). Document project-specific values here — not the framework defaults.
