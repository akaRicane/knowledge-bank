AdonisJS

Full-stack Node.js framework (TypeScript). Covers the service layer, authentication, ORM, mailer, validation, and testing. Common patterns apply across versions; version-specific notes are in their own folders.

Common knowledge

These documents describe patterns that apply broadly to AdonisJS projects, independent of the version in use.

  • Authentication Token-based (OAT) and cookie-based auth patterns, user lifecycle, roles.
  • Models Lucid ORM models, ULID public ID pattern, relationships, factories, seeders, migrations.
  • Services Backend service layer, API client services (UserApiService, ContentApiService), request pattern.
  • Mailer SMTP configuration, sending mail, MAILER_MOCK system, test faking and smoke tests.
  • Validation VineJS validators, schema patterns, error response shapes.
  • Testing Japa setup, DB truncation pattern, functional vs unit tests, factory usage, Inertia assertions.
  • Tuyau Type-safe API client and Inertia routing layer. TuyauProvider, typed Link/useRouter, fetch replacement, CSRF, route filtering, two-app monorepo pattern.

Two-app monorepo pattern

Projects may use two independent AdonisJS apps in the same monorepo: a backend (REST API, token auth, PostgreSQL) and a webapp (Inertia SSR, cookie auth, no database). The webapp has no direct DB connection — it proxies all data through backend HTTP endpoints.

ℹ
The auth models differ: the backend uses @adonisjs/auth with DbAccessTokensProvider (OAT); the webapp uses cookie-based token forwarding (no auth guard), storing the OAT in an oat_token httpOnly cookie.

Shared conventions

  • Path aliases use the # prefix: #models/user, #services/user, etc.
  • Prettier: @adonisjs/prettier-config — run prettier --write . after editing.
  • ESLint: @adonisjs/eslint-config — run eslint . after editing.
  • Typecheck: tsc --noEmit after non-trivial changes.
  • Internal primary keys (id) are never exposed in API responses; use publicId (ULID).
  • Empty strings in request bodies are converted to null via convertEmptyStringsToNull: true.
